# Privacy policy

**Effective date:** October 1, 2026

CloseWise is designed to operate entirely on the device.

## Data accessed

CloseWise can access the installed application inventory, recent foreground-activity events, and the visible content of Android App info screens while a cleanup is running. This access is used only for filtering, exclusions, recent-activity discovery, and Force-stop automation.

## Data collection and transmission

CloseWise does not collect, upload, sell, rent, share, or monetize personal data. It contains no internet permission, analytics, advertising SDK, account system, telemetry, remote configuration, or cloud backend.

## Local storage

The app stores only operational preferences on the device, including excluded package names and temporary cleanup-session state. This data is removed when app storage is cleared or the app is uninstalled.

## Accessibility

The accessibility service is restricted to Android Settings. It finds and activates Force stop and confirmation controls. CloseWise does not use accessibility to read messages, type text, capture passwords, inspect unrelated apps, or transmit screen content.

## Usage Access

Usage Access identifies applications foregrounded during the previous 15 minutes. This data remains on the device.

## Contact

For privacy questions, open an issue at [github.com/k5rxd/CloseWise/issues](https://github.com/k5rxd/CloseWise/issues).
